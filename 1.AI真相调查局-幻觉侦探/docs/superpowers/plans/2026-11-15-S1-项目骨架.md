# S1 项目骨架 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭出可在干净环境打开、运行、测试、导出的 Godot 项目骨架（3 个 Autoload + 页面注册表 + 主菜单 + 8 占位页 + 主题 + 零依赖测试运行器 + Windows 导出）。

**Architecture:** 按系统设计 v0.3 的分层骨架落地：Presentation（场景）经 GameFlow 发起变更，GameFlow 编排并持有会话，Domain 为纯逻辑（S1 只落枚举与 DTO 壳），ContentLoader/SaveManager 为 infrastructure。3 个 Autoload 固定顺序 SaveManager → ContentLoader → GameFlow。

**Tech Stack:** Godot 4.7.2-stable + GDScript；零第三方依赖 headless 测试运行器（`godot --headless --path . -s res://tests/run_tests.gd`）。

**Spec:** `docs/stages/S1-项目骨架-详细设计.md`（v0.2）

## Global Constraints

- Godot 4.7.2 固定，`config/features=PackedStringArray("4.7", "GL Compatibility")`，渲染 `gl_compatibility`。
- 零联网、零第三方依赖、零 Steamworks/账号/付费（S1 不含 `[input]` 段）。
- 资源路径全小写、严禁大小写混用（Windows 大小写敏感）。
- Autoload 顺序 SaveManager → ContentLoader → GameFlow（`project.godot` 声明顺序即加载顺序）。
- 1280×720 + `canvas_items` stretch + `aspect=keep`。
- 工程根 = `1.AI真相调查局-幻觉侦探/`；git 仓库在顶层 `ai_game/`（monorepo）。

## Review Focus

1. Autoload 顺序错 → `GameFlow._ready()` 空引用（test: `get_index()` 升序 + `_ready()` 真实访问）。
2. 页面路径拼错/漏页 → `goto` 失败（test: `PAGE_SCENES` 恰 9 项 + `ResourceLoader.exists`）。
3. 占位页缺返回按钮 → 进得去出不来（test: 每个占位页有 `BackButton`）。
4. 设置默认值缺/错 → S2 存档 schema 破坏（test: 4 键精确值 + 类型）。
5. `goto` 未知页 → 应返回 false 且不切场景（test: `can_goto(999)==false`、`goto(999)==false`）。
