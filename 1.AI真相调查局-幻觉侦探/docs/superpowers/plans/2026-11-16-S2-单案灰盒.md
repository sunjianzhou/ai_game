> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现案件 01 的完整可玩闭环（简报 → ORION 报告 → 判定 3 条陈述 → 关联证据 → 提交最终建议 → 评分 → 复盘），领域纯函数 + 数据驱动 + 可自动测试。

**Architecture:** 在 S1 骨架上落地系统设计 v0.3 的 Domain 层：枚举/目录/定义类型 → 会话/结果类型 → 纯函数 Scorer → 内容 JSON → ContentLoader 加载校验 → GameFlow 状态机 → 灰盒 UI。Domain 纯逻辑（RefCounted、不碰引擎场景/文件/信号），Presentation 经 GameFlow 变更。

**Tech Stack:** Godot 4.7.2 + GDScript；零依赖 headless 测试运行器。

**Spec:** `docs/stages/S2-单案灰盒-详细设计.md`（v0.2）

## Global Constraints

- 评分 100 = 60 判定准确度 + 30 证据关联 + 10 最终建议，再减提示 −5（Spec §11）。
- **证据分公式（每条 claim 均分）**：`evidence = Σ over matched claims of (30/n_claims) × (raw_i/key_i)`，`raw = clamp(hit − λ·min(unrelated,key) − μ·miss, 0, key)`，`unrelated = |linked \ related|`，λ=μ=1。精确期望值（case_001，key 3/1/1）：全对 100 / 2对+1cautious 80 / 2对+1错 70 / 全 unverified 60 / 全错+正确动作 10 / 全错+错动作 0。
- **领域内 label/action 一律存 string code**（`judgements[claim_id]="supported"`、矩阵键 `"supported"`、`final_action="revise"`）；enum int 仅用于目录遍历/UI 排序。
- **枚举访问**：`class_name Enums`（`enums.gd`）内定义 12 个 enum + static helper `Enums.claim_label_value(s)->int`（未知 -1）等；跨脚本用 `Enums.ClaimLabel.supported`。
- **CaseSession**：`_init(def)`、`static from_dict(d, def)`、`begin_briefing()`（NOT_STARTED→BRIEFING）；`submit_final` 幂等语义：非 READY/SUBMITTED → false；READY 首次 → true；SUBMITTED 同参 → true 且 result 不变；SUBMITTED 异参 → false。
- **CaseResult/ClaimResult**：`points`=该 claim 的准确度分（不含证据）、`max_points=60/n_claims`、`breakdown={accuracy,evidence,final_action}`、`final_action_detail={action,weight,points}`；claims 数组按 case_def 定义顺序。
- GDScript 类型约定（Spec §4）：可空字段用 `Variant`、JSON 数字 `int()`、typed array 逐元素构造、`roundi()` 取整。
- **测试运行**：新建 `class_name` 文件后先 `godot --headless --path <proj> --import` 刷新全局类缓存，再跑测试。测试文件契约 `static func run(tree) -> Array[String]`。
- **git**：仓库根 `/Users/linmiao/work/ai_game`；每步 `git -C /Users/linmiao/work/ai_game add -A && git -C /Users/linmiao/work/ai_game commit ...`（`-A` 同时含新建与修改，不要用 `-am`）。
- 资源路径全小写；零联网/零第三方依赖。

## Review Focus

1. Σkey_count==0 → Scorer 除零（test: 空 case 返回 total=0、三分解全 0，不崩溃）。
2. 证据门控/均分失效 → 全 unverified 套利 ≠ 60（test: 全 unverified + 全 key + revise == 60）。
3. 未知枚举字符串静默默认（test: `Enums.*_value("bad")` 返回 -1，ContentLoader 报 `invalid_enum`）。
4. 报告 claim 重复/孤儿引用（test: 负例 fixture 触发 `report_claim_duplicate`/`report_claim_missing`）。
5. READY_TO_SUBMIT 锁死证据关联（test: READY 下 `link_evidence`/`judge_claim` 仍返回 true 且保持 READY）。
