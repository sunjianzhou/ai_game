## Global Constraints

- 案 02/03 照 case_001 全量字段；`knowledge_cards.json` 含 card_fc_002/003 且 `debrief.knowledge_card_id` 对应。
- 校验补全（§5）：日期正则+分量校验、时间戳比较、outdated 第二条件（supports+当前有效）、supported 对称、table 形状、invalid_type、标签一致性。
- 解锁：`start_case` 守卫（非 always 需前一案完成）；case_select 多案件按 order 排序 + 锁定/最高分。
- 回归：S1/S2/S3 的 13 个测试文件全绿。

## Review Focus

1. 时间截断误判（test: valid_until == as_of 当天、created_at == as_of、datetime/日期混排）。
2. outdated 第二条件误伤（test: 旧证据 + 有效新 supports → 不判 outdated）。
3. claim_003 空 key 阻塞（test: unverified + checked_no_match 证据不崩）。
4. 解锁绕过（test: 未完成前一案 → start_case 返回 false）。
5. 标签一致性误报（test: supported 无有效 supports → 报错；contradicted 无反驳 → 报错）。
