# 《AI 真相调查局：幻觉侦探》测试说明 + 反馈表

> 这是一款**虚构案件**的解谜游戏（非真实模型测评）。你在测试一个"还在开发中"的游戏，目的是帮我们发现哪里不好玩、哪里看不懂，**不是考核你**。随便玩、随便试错。

## 一、怎么玩（30 秒上手）

你扮演 AI 事实调查员，审查 AI 助手 ORION 生成的报告，判断报告里的每句话是否可信。

1. **点报告里带编号的句子**（选中它）。
2. **选一个判定**：这句话属于下面四类之一——
   - **有证据支持**：证据足够证明它对。
   - **证据矛盾**：证据直接反驳它。
   - **缺乏证据**：证据不足以确认、也不足以反驳（**不是"假的"**）。
   - **信息过时**：曾经正确，但已被新资料取代。
3. **点右侧证据卡，关联到当前句子**（支持或反驳都算关联）。
4. 判完所有句子后，**去提交**，选一个处理建议（批准发布 / 附带限定发布 / 暂缓发布 / 退回修订）。
5. 看分数和复盘。

> 每个案件 10–20 分钟。**第一个案件会教你区分"缺乏证据"和"证据矛盾"**——这是本作最重要的一个知识点。

## 三、体验反馈（想到啥写啥）

1. 有没有哪里**卡住不知道下一步**？在哪？
2. 四类判定（尤其"缺乏证据" vs "证据矛盾"、"信息过时" vs "证据矛盾"）**分得清吗**？哪两个最容易混？
3. 哪个案件最让你觉得"哦原来是这样"？哪个觉得"这到底在干嘛"？
4. **分数和扣分看得懂吗**？（判定 60 + 证据 30 + 动作 10，满分 100）
5. **玩完第一案后，想不想继续下一案？**（想 / 一般 / 不想）
6. 有没有崩溃、乱码、按钮点不动、文字看不清的情况？在哪？
