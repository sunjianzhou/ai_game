## 1. 目标与验收标准

**目标**：搭出能在干净环境打开、运行、导出的 Godot 项目骨架，把系统设计的架构骨架（3 个 Autoload、页面注册表、目录结构、主题、零依赖测试）落到工程上。

**验收标准（全部满足才进 S2）**：
1. 干净环境按 README（含首次导入步骤）打开项目并运行到主菜单。
2. 主菜单 4 个按钮可用：开始调查/图鉴/设置跳到对应占位页，退出关游戏；**每个占位页都能返回主菜单**。
3. 3 个 Autoload 按序加载、无空引用、无初始化错误；GameFlow 的 `_ready()` 能实际调用 SaveManager 与 ContentLoader（顺序被真实验证）。
4. 1280×720 窗口，缩放时 UI 按 `canvas_items` 拉伸不变形。
5. `godot --headless --path . -s res://tests/run_tests.gd` 退出码 0（覆盖：页面注册表、场景冒烟、autoload 顺序、设置默认值、导航允许/拒绝、ProjectSettings/主题断言）。
6. Windows 导出**成功且产物齐全**（`.exe` + `.pck`，大小非零）；真机启动验证放 S5（本机 macOS 交叉导出无法启动 Windows exe，见 DECISIONS）。
7. `README.md` 写清五步：安装 Godot、首次导入、运行、测试、导出。

## 7. Autoload 骨架与 DTO 契约（本阶段冻结，S2 复用签名不变）

### 7.1 DTO 壳（S1 定义，S2 只加字段不加签名）

```gdscript
# scripts/persistence/player_progress.gd
class_name PlayerProgress
extends RefCounted
var save_version: int = 2
var settings: Dictionary = { "volume_master": 0.8, "volume_music": 0.6, "font_scale": 1.0, "window_mode": "windowed" }
var progress: Dictionary = {}        # case_id -> {completed, best_score}
var collected_cards: Array = []
var earned_titles: Array = []
var last_case_id: String = ""
func to_dict() -> Dictionary
static func from_dict(d: Dictionary) -> PlayerProgress
```

```gdscript
# scripts/content/case_load_result.gd
class_name CaseLoadResult
extends RefCounted
var ok: bool = false
var case_def = null        # S2 为 CaseDefinition；S1 恒 null
var errors: Array = []     # [{case_id, field, code, message}]
static func success(case_def) -> CaseLoadResult   # ok=true, errors=[]
static func failure(errors: Array) -> CaseLoadResult  # ok=false, case_def=null
```

```gdscript
# scripts/content/case_catalog.gd
class_name CaseCatalog
extends RefCounted
var cases: Array = []      # [{case_id,title,difficulty,order,unlock_condition,summary}]
```

### 7.2 SaveManager（`scripts/persistence/save_manager.gd`）

```gdscript
extends Node
signal setting_changed(key, value)
var base_path: String = "user://"            # 路径注入点（测试传临时目录）
func load() -> PlayerProgress                 # S1 返回默认 PlayerProgress（不读盘）
func save(progress: PlayerProgress) -> bool   # S1 不落盘，返回 true（真实原子写/迁移在 S2）
func get_setting(key: String) -> Variant      # 未知键返回 null；默认值在 _ready() 初始化
func set_setting(key: String, value) -> void  # S1 仅更新内存副本 + 发信号；非法值 clamp/忽略并记日志
```

设置默认值（写死，进入 S2 存档 schema）：`volume_master=0.8`、`volume_music=0.6`、`font_scale=1.0`、`window_mode="windowed"`。

### 7.3 ContentLoader（`scripts/content/content_loader.gd`）

```gdscript
extends Node
var content_root: String = "res://content"    # 路径注入点
func get_catalog() -> CaseCatalog             # S1 返回空 catalog（cases=[]）
func load_case(id: String) -> CaseLoadResult  # S1 返回 failure([{code:"not_found"}])
func get_knowledge_cards() -> Dictionary      # S1 返回 {cards:[]}
func get_titles() -> Dictionary               # S1 返回 {titles:[]}
```

### 7.4 GameFlow（`scripts/game_flow/game_flow.gd`）

```gdscript
extends Node
signal case_started(id)
signal case_state_changed(from, to)
signal case_submitted()
signal case_completed(id)
enum Page { MAIN_MENU, CASE_SELECT, BRIEFING, INVESTIGATION, FINAL_VERDICT, RESULTS, DEBRIEF, COLLECTION, SETTINGS }
const PAGE_SCENES := { Page.MAIN_MENU: "res://scenes/menu/main_menu.tscn", /* 其余 8 项 */ }
var current_session = null      # S1 恒 null（S2 为 CaseSession）
var current_result = null       # S1 恒 null（S2 为 CaseResult）
var previous_page: int = -1     # 仅用于设置页返回，不承载业务状态
var _settings_cache = null      # _ready() 里存 SaveManager.get_setting 结果，验证 autoload 顺序
var _catalog_cache = null

func _ready() -> void:
    _settings_cache = SaveManager.get_setting("volume_master")   # 若 SaveManager 未先加载，这里就是 null/报错
    _catalog_cache = ContentLoader.get_catalog()                 # 同上，验证 ContentLoader 先于 GameFlow

func can_goto(page: int) -> bool    # 无副作用：page 是否在 PAGE_SCENES 中
func goto(page: int) -> bool        # can_goto 为真才 change_scene_to_file；返回值反映其 Error
func back() -> bool                 # 返回 previous_page（-1 则回 MAIN_MENU）
func start_case(id: String) -> bool # S1 返回 false（S2 实现）
func end_case() -> void             # S1 no-op（清 current_session/result 引用）
```

S1 不做 phase 守卫（phase 状态机 S2 接入）；`goto` 只校验 PAGE_SCENES 存在。

## 11. 测试骨架（零依赖 headless）

运行命令（README 统一此写法）：`godot --headless --path . -s res://tests/run_tests.gd`（macOS 用 `/Applications/Godot.app/Contents/MacOS/Godot` 或自建 alias）。

**契约（写死，S2 复用）**：
- `run_tests.gd`：`extends SceneTree`，在 `_initialize()` 里执行（autoload 此时已注册到 root）；收集失败消息，失败数 >0 时逐条打印并 `quit(1)`，否则 `quit(0)`。
- 取 autoload 用 `root.get_node("SaveManager")`（SceneTree 无 `get_node`）。
- `test_s1_skeleton.gd`：`static func run(tree: SceneTree) -> Array[String]`，返回失败消息数组。

`test_s1_skeleton.gd` 断言：
1. **页面注册表**：`PAGE_SCENES` 恰 9 项；每项 `ResourceLoader.exists(path)`。
2. **场景冒烟**：逐个 `load(...).instantiate()` 9 个场景，断言关键节点（主菜单有 4 按钮 + footer + ProgressLabel；每个占位页有 BackButton）。
3. **Autoload 顺序**：`root.get_node("SaveManager").get_index() < root.get_node("ContentLoader").get_index() < root.get_node("GameFlow").get_index()`；且 `GameFlow._settings_cache == 0.8`、`_catalog_cache` 非空（证明 `_ready()` 里真实访问过）。
4. **设置默认值**：4 个键的精确值与类型（`volume_master==0.8`、`volume_music==0.6`、`font_scale==1.0`、`window_mode=="windowed"`）。
5. **导航允许/拒绝**：`can_goto(GameFlow.Page.MAIN_MENU)` 为 true；`can_goto(999)` 为 false；`goto(999)` 返回 false 且不切场景。
6. **ProjectSettings/主题**：`display/window/stretch/mode=="canvas_items"`、`aspect=="keep"`、`viewport_width==1280`、`viewport_height==720`、`renderer/rendering_method=="gl_compatibility"`、`theme.tres` 的 `default_font != null` 且 `default_font_size==16`。

> 说明：`--headless -s` 下 autoload 随项目加载（`_initialize()` 时可用）；instantiate Control 场景 headless 可行；`ResourceLoader.exists` 对导出后的 remap 资源也比 `FileAccess` 可靠。

## 17. 与 S2 的接口

S2（单案灰盒）将：
1. 复用 3 个 Autoload 的**类型化签名**（S1 已冻结；S2 只给 DTO 加字段、给方法补实现，不改签名）。
