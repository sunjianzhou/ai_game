# 《AI 真相调查局：幻觉侦探》阶段规划路线

- 更新日期：2026-11-15
- 用途：本游戏的**进度总控**。只记录阶段清单、每个阶段要做什么、当前完成状态。每个阶段的详细设计与实现拆分到各自文档（见 `docs/`）。
- 阶段划分依据：《AI真相调查局-幻觉侦探研发任务书.md》第 9 节（Milestone 0–5）。

## 阶段总览

| 阶段 | 名称 | 主要目标 | 状态 |
|---|---|---|---|
| S0 | 详细设计 | 系统架构、功能模块、领域模型、数据格式、状态机、评分与存档设计 | ✅ 完成 |
| S1 | 项目骨架（M0） | Godot 项目可启动、主菜单空壳、主题/分辨率、Git、文档、Windows 导出 | ✅ 完成 |
| S2 | 单案灰盒（M1） | 一个完整可玩案件：简报→报告→陈述→证据→判定→结论→评分→复盘 | ⬜ 未开始 |
| S3 | Vertical Slice（M2） | 视觉样式、动效音效、证据卡交互、状态反馈、存档、帮助、分辨率适配 | ⬜ 未开始 |
| S4 | 三案内容 Alpha（M3） | 案件 01/02/03、事实核查、难度递进、复盘知识点 | ⬜ 未开始 |
| S5 | 封闭测试与修正（M4） | 测试 Build、反馈收集、问题修复、回归测试 | ⬜ 未开始 |
| S6 | 发行候选版（M5） | Release Build、设置/图标/字体/音频、存档兼容、无网启动、Steamworks 评估 | ⬜ 未开始 |

## 各阶段说明

### S0 详细设计
- 目标：写代码前先确定系统架构、功能模块划分、领域模型、数据格式、状态机、评分与存档设计。
- 产出：《docs/系统设计.md》（整体）；进入后续各阶段前，再补该阶段的详细设计文档（含明确输入输出）。
- 完成标准：整体设计经负责人确认；核心模块边界清晰；数据 schema 与评分逻辑可测试。
- 状态：✅ 完成

### S1 项目骨架（M0）
- 交付：Godot 项目可启动；主菜单空壳；基础主题与 1280×720 分辨率；Git 仓库与文档；Windows 导出成功 + 产物齐全（不接 Steam；真机启动验证在 S5）。
- 详细设计：《docs/stages/S1-项目骨架-详细设计.md》
- 状态：✅ 完成

### S2 单案灰盒（M1）
- 交付：案件简报；AI 报告；3–5 条陈述；证据查看；四类判断；证据关联；提交结论；评分与复盘。
- 验收：无开发者指导的测试者能独立完成整个案件；不同答案分数符合设计；判定逻辑可自动测试。
- 详细设计：《docs/stages/S2-单案灰盒-详细设计.md》
- 状态：⬜ 未开始

### S3 Vertical Slice（M2）
- 交付：完整视觉样式；基础动效与音效；证据卡交互；状态反馈；本地存档；帮助说明；1280×720 与常见桌面窗口适配。
- 详细设计：《docs/stages/S3-VerticalSlice-详细设计.md》
- 状态：⬜ 未开始

### S4 三案内容 Alpha（M3）
- 交付：案件 01「不存在的引用」、02「过期的真相」、03「看似合理的推断」；每案事实核查记录；正确答案与证据关联有依据；难度递进。
- 详细设计：《docs/stages/S4-三案内容-详细设计.md》
- 状态：⬜ 未开始

### S5 封闭测试与修正（M4）
- 交付：测试版 Build；测试说明；反馈表；问题分类；修复记录；回归结果。
- 详细设计：《docs/stages/S5-封闭测试-详细设计.md》
- 状态：⬜ 未开始

### S6 发行候选版（M5）
- 交付：Windows Release Build；视资源测 macOS；最终设置/图标/字体/音频；存档兼容；无网启动测试；低配测试；Steamworks 集成评估；Content Survey 与素材授权清单。
- 详细设计：《docs/stages/S6-发行候选-详细设计.md》
- 状态：⬜ 未开始
