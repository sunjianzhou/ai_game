## 约定

- 每个游戏一个独立文件夹，各自独立上下文与子 agent。
- 每个游戏文件夹内有 `阶段规划路线.md`，记录该游戏的阶段清单、每个阶段要做什么、当前完成状态——用于**进度总控**。
- 每个阶段进入前，先产出该阶段对应的**详细设计文档**（含明确输入/输出），便于阶段与模块间交互，避免"一锅炖"后打补丁。
- 阶段顺序与验收以《长期规划.md》Phase 0–7 及各游戏研发任务书为准。
